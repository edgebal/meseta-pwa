# Qué Meseta Es

PWA para iOS/Android: apuntá el teléfono a una meseta o cerro en el horizonte y la identifica usando brújula, inclinación (acelerómetro), relieve SRTM (OpenTopoData) y topónimos de OpenStreetMap (Overpass), sobre mapa OpenTopoMap.

Instalación: abrir la página en Safari → Compartir → Agregar a inicio.
